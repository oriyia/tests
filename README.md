# tests

Скилл тестов для ИИ-агента Claude Code. Прочитав этот файл, вы узнаете, чему скилл учит агента,
когда агент его поднимает и как скилл попадает на машину.

## Чему учит

Скилл — инструкция для агента в файле `SKILL.md`. Этот учит агента:

- сначала тест, который падает, потом код;
- красный тест чинить кодом, а не ослаблять проверку;
- каким должен быть тест и где его держать;
- тест без нужного окружения пропускать явно и с причиной, а о результате говорить по выводу
  команды, запущенной сейчас.

## Когда агент его поднимает

Агент постоянно видит краткое описание скилла и поднимает его, когда задача подходит под описание:
когда агент добавляет поведение, чинит ошибку, пишет или правит тесты. В проекте по Стандарту
процесса разработки Центра к скиллу ещё направляет скилл-оркестратор `standard`.

## Как скилл попадает на машину

В Стандарте скилл ставит скрипт `install` репозитория `standard`: этот репозиторий лежит в папке
Стандарта рядом со `standard`, а `install` ставит на него ссылку `~/.claude/skills/tests`, где
Claude Code ищет скиллы пользователя. Как получить папку Стандарта — README репозитория `standard`.

Вне Стандарта склонируйте репозиторий и поставьте ссылку сами:

```bash
git clone <адрес Gitea>/<организация>/tests.git ~/projects/tests
mkdir -p ~/.claude/skills
ln -s ~/projects/tests ~/.claude/skills/tests
```

Проверка — `ls -l ~/.claude/skills/tests` показывает ссылку на папку репозитория. Агент увидит скилл
в новой сессии `claude`. Как править скилл — [CONTRIBUTING.md](CONTRIBUTING.md).
