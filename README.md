# tests

`tests` — скилл для ИИ-агентов, который задаёт подход к разработке через тесты (TDD).
Агент описывает нужное поведение тестом, проверяет, что тест падает по ожидаемой причине,
и вносит минимальное изменение, чтобы тест прошёл. После этого агент может привести код
в порядок, проверяя тестами, что поведение сохранилось.

## Когда применять

Скилл подходит для добавления нового поведения, исправления ошибок и правки тестов. Он также
нужен, если после изменения упала проверка или пора сообщить о результатах запуска тестов.

## Основа в Superpowers

`tests` опирается на [`test-driven-development` из плагина Superpowers `v7.0.2`](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/test-driven-development/SKILL.md).

## Что добавляет `tests`

`tests` дополняет цикл TDD правилами работы со всем набором проверок проекта.

- Агент запускает тесты проекта до правок. Так по итоговому запуску можно отличить новые
  падения от тех, что уже были.
- Скилл поясняет, когда можно изменить ожидаемый результат теста — при изменении требования
  или ошибке в прежнем ожидании. Он также показывает, какие правки теста или настроек запуска
  ослабляют проверку.
- Если тесту требуется недоступное оборудование или сервис, агент отмечает пропуск с причиной.
  В отчёте он указывает команду последнего запуска и итог из её вывода, включая число
  упавших и пропущенных тестов.
- Скилл объясняет, как размещать тесты и тестовые данные в Python, Node.js, Go и Rust и как
  подтвердить запуск конкретного теста. Для ресурсоёмких тестов он учитывает
  доступную память при выборе числа параллельных запусков.
